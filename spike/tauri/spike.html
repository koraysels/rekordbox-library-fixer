Rekordbox Library Fixer: Tauri test build

This build tests whether a smaller version of the app runs on your computer. It doesn't change anything: your library is copied to a temporary folder and only read. Run the three checks, then copy the results into the GitHub issue.

1. Read your rekordbox library

2. Play a track

3. Look at the app screen

Opens the app's normal screen. It isn't connected to anything yet, so buttons do nothing. Check that it looks right, then close the window.
